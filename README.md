# Ardapoeia Site

⚠️ This repository contains only the build output of the [Ardapoeia project](https://github.com/William65536/ardapoeia) and is used for static hosting via GitHub Pages. Source code is _not_ maintained here. Please submit PRs to the development repo.

## About

A walkable map of Middle‑Earth set during the Third Age, playable in your browser.

> **Note:** This project is in early development. Expect breaking changes. Contributions encouraged! :)
